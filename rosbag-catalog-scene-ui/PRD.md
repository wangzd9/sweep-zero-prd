## 6. 使用能力与后续可视化

### 6.1 API 与最小闭环界面

最小闭环沿用 `/bags?view=slices|originals|all` URL：标签依次为“切片”“原始数据”“全部”。`originals` 按原始数据语义覆盖自建、英伟达及场景输入；英伟达现有 `NOT_APPLICABLE` 角色不得因只筛 `ORIGINAL` 被漏掉。数据类型筛选分别为自建数据集、英伟达数据集、切片原始数据；筛选与视图组合结果必须一致，旧书签和旧入口可访问。默认仍可为“切片”。

场景流水线详情按 `pipeline_type=SCENE_SLICE` 分支展示实际 `PRECHECK/EXTRACT/INFER/SEGMENT/WRITE/VALIDATE/PUBLISH/REGISTER` 步骤的状态、Attempt、错误、产物与父/子包链接；执行位置标为处理机，模型标为远端服务。场景运行不显示自建 Phase0/Phase1/Phase3、A100 目录或不适用的强制重试选项。自建/NVIDIA 详情按原路线展示。

切片展示场景、时长、自动识别标记、父包和获取操作；原始包展示本次所选场景的状态及切片数，不固定五列。详情双向跳转并展示生成版本。人工纠错和下架保留原始模型结果、操作者和原因；下架不删除文件。预览是非阻断辅助产物。
